# Before assembly

- Use the product-specific manual when it is available. This generic reference
  does not replace manufacturer part numbers, torque limits, or warnings.
- Count panels, fasteners, fittings, and tools before joining parts.
- Keep load-bearing furniture unloaded until every connection is inspected.

# Orientation and reversible joining

1. Match labels, finished faces, pilot holes, and connector directions.
2. Start every fastener by hand and keep joints adjustable.
3. Check diagonals and all feet on a flat surface before final tightening.
4. Tighten gradually in the sequence required by the product manual.

# Stop conditions

Stop and request clarification when a part number is missing, a hole pattern
does not match, a fastener binds, a panel cracks, or the product manual conflicts
with this generic reference.

# Final inspection

- Confirm every connector is present and seated.
- Confirm the frame is square and does not rock.
- Recheck manufacturer warnings before applying any load.

Provenance: bundled generic flat-pack practice policy. This document describes
safe inspection boundaries; it is not evidence that the current assembly is
correct.
