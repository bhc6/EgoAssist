# Item evidence policy

This is an original EgoAssist checklist policy, not an official travel or security standard.

Keep three statements separate: what the user needs, what is currently seen or
reported, and what the user confirms is packed. A remembered location is historical
evidence, not a current inventory. State the source when this distinction matters.

Unknown travel rules, medical supplies, battery restrictions and identity-document
requirements require the user's authoritative source. Do not infer those requirements.
Confirming a checklist step records the user's assertion; it is not independent
physical verification.
