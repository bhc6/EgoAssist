# 实时交互失效与长会话延迟修复（2026-09-25）

本次由实际使用中“文字和说话都没有反应”触发。故障发生于 9 月 24 日晚；排查和验证跨越午夜。原始记录保留在本机，本文不发布用户会话原文。

## 已确认的原因

首页能打开不代表回答链路健康。原会话日志显示输入已到达服务器；21 次路由中有 15 次 TimeoutError。“你好”从接收到开始分类等待约 70 秒，分类再失败，最终却记录为静默完成。另一次文字输入被误走麦克风链路，约 30 秒才回答，供应商记录的输入达到 102087 tokens。这些故障发生时使用 Qwen，不能归因于后来才启用的 OpenRouter。

| 缺陷 | 后果 | 修复 |
| --- | --- | --- |
| 恢复队列默认丢失 explicit 标记 | 文字进入麦克风通道 | 入队与执行均从持久化 source 恢复输入通道 |
| 分类失败的 uncertain/silent 被当成有效控制 | 输入被静默完成，用户无反馈 | 失败明确落账并向页面报错；失败决策不执行控制 |
| 启动、恢复及投影多次深拷贝整个日志 | 旧媒体、模型审计挤占主线程 | 按事件类型读取；增量游标先过滤再复制 |
| 后台回答轮询对每条旧回答重新复制全部回答 | 每 250 ms 重复平方级历史处理，阻塞超时回调 | 每轮固定读取两次回答映射 |
| 本轮场景与证据被重复追加到模型长期会话 | 上下文逐轮增长、旧场景干扰回答 | 本轮数据放入本次请求；保留时间、检索证据、写入结果与运行状态 |
| 重连直接回放原始历史投影 | 绕过已经生效的上下文预算 | 使用 ContextHarness.build 的预算内视图回放 |
| 预取与消费阶段使用不同的语义字典 | 有效记忆被判为 scope-or-policy-changed | 检索验收使用原始查询契约；执行使用规范化意图，仍验证用户、会话和权限 |
| 普通文字问答也等待历史视觉，前台证据过大 | 简单问题承担不必要的视觉和模型耗时 | 无当前帧时，仅记忆查询进入文字历史视觉；限制前台原文及长事件投影 |

连续输入复测还发现 Decisions 的内部 2 秒请求时限可能早于路由总时限耗尽。新增的重试最多一次，仅使用原有总时限的剩余时间；认证/账户等不可重试错误不重试，耗尽总时限不重新开始一个完整超时周期。失败仍保留输入和后台记忆恢复，不自动重放工具或控制操作。

## 预算与记忆边界

- 在线原文检索：`EGOASSIST_LIVE_EVIDENCE_CHARS=6000`，允许 1000–24000；近期会话 `EGOASSIST_LIVE_RECENT_CHARS=2000`，允许 500–8000；最多 6 个命中锚点、4 个近期来源。
- 前台长事件展示最多 2 个事件，每个保留最近 2 个来源和 4 个阶段，并明确标记省略。来源 ID、原文、时间、人物归属和不确定性保留。
- 原始日志、完整事件浏览及离线历史检索未删减。历史检索默认预算仍为 24000 + 8000 字符。
- 较小在线窗口可能减少某轮回答可见的证据；它不是记忆删除，也不是召回质量不变的证明。后续记忆研究应单独评估准确率、漏召回和时延的权衡。

## 同一长会话的真实接口测量

隔离账户加载同一份 9193 行长会话副本；禁止重放旧待办/工具操作。两条文字分别验证简单计算和上一轮指代，语音由真实 TTS 生成，经 WebSocket 音频输入及真实 ASR/回答服务处理。所有下列顺序问答均回答正确并收到音频。

| --- | --- | --- | --- |

| real-r2 | 10.29 / 10.24 秒 | 6.95 秒 | 修复轮询和记忆契约 |
| real-r3 | 5.61 / 4.59 秒 | 5.83 秒 | 加入前台证据预算与历史视觉门控，Qwen 路由 |

| real-r5 | 4.86 / 3.65 秒 | 4.77 秒 | 本轮补充证据改为随请求传递；连续输入第二条遇到 Decisions 内部超时，整次验收失败 |
| real-r6 | 4.60 / 3.74 秒 | 4.23 秒 | 限时重试修复后，顺序与连续输入验收通过；本次实际未触发重试 |

不要把 real-r1 当成完全未修复的线上故障基线，也不要把不同路由/供应商波动当作严格消融。r5 的失败保留，不能只展示前三条成功请求。r4 的连续输入回执由串行 HTTP 轮询拖慢测试消费，不作为服务回执时延；后续版本并发消费 WebSocket。

启动剖析（同一长会话、带 cProfile）从约 49.55 秒降至约 6.4 秒；这个数包含剖析开销，不能作为正常冷启动 SLA。真实顺序文字回执约 0.24–0.34 秒。测量未覆盖物理麦克风、扬声器、持续摄像头输入或长时间 p95。

r6 连续两条文字回执均约 632 ms，两条持久化回答在约 7.02 秒内完成。五条新输入的记忆读取均无验收失败。它证明本次样本通过，不意味着供应商不再可能超时；重试恢复、取消与总时限由确定性回归额外验证。

## 验证与复现

回归覆盖持久化输入通道、分类失败反馈、预算内回放、删除后游标失效、固定次数后台轮询、记忆预取契约、前台证据保真和分类重试总时限。确定性回归需显式选择 Qwen，避免本机 `.env` 的可选 Decisions 后端与旧 Qwen 模拟器不匹配；Decisions 本身有独立测试。

最终全量回归：**841 passed，3 条 aiohttp 弃用警告**（109.78 秒）。此前默认本地配置的回归在 Qwen 模拟器与 Decisions 包装器之间出现 `requestMetrics` 不匹配；失败记录保留，显式选择测试后端后通过。真实浏览器（Edge、隔离新账户、实际点击发送、无模拟接口）完成回答约 3.26 秒，无页面 JavaScript 错误，刷新后回答仍在。真实语音测试通过音频包输入，未验证物理声学设备。

验证后已重启本地 `127.0.0.1:8770` 服务，新进程监听正常、首页 HTTP 200、启动 stderr 为空。原用户会话未被测试输入污染；旧浏览器页需要刷新或重新连接才能使用新服务。
