# EgoLifeQA A-D 四选一统一对照

账户恢复后，本轮已完成 A-D 全部 360 次有效选择题回答及证据评审。四组准确率分别为 A 27.78%、B 21.11%、C 32.22%、D 20.00%。C 的数值最高，但按视频分组的配对差异置信区间包含 0，不能认定它稳定优于 A；本轮不更改默认检索方案。

**所有指标放在同一张[完整对照表](../artifacts/egolife-abcd-mcq-20260914-r2/comparison.md)中。** 机器可读结果见[summary.json](../artifacts/egolife-abcd-mcq-20260914-r2/summary.json)，其中包含逐 seed、按视频时间组和相对 A 的配对比较。最终核验时间为 2026-09-14 23:06（Asia/Shanghai）。

## 统一条件

- 同一批官方 JAKE DAY2-DAY7 的 30 道四选一题，已经暴露，属于回归评测；不是新的独立测试，也不宣称跨参与者泛化。
- 固定 `qwen-flash`，温度 0，seed 为 17、43、91；每组计划 90 次回答，总计 360 次。seed 同时用于执行顺序和请求参数，不保证供应商严格复现，不扩大独立样本量。
- 所有组必须从 A/B/C/D 中选择一个，输出 `{"choice":"A"}` 形式的 JSON。证据不足也选择最可能的选项，不允许拒答。完成请求但输出格式不符合约定时计错；未完成请求不冒充错误答案。
- 所有组只用题干检索，选项仅传给回答模型；正确选项、目标时刻、目标来源不参与检索或答案生成。正确选项和目标时刻只在预测落盘后的评分阶段读取。
- 共享 Timeline 默认 256 条扫描预算及同一硬约束候选池，最终最多取 5 条来源；所有组给回答模型的证据均为完整来源原文，格式一致。
- 每个提问时刻只保留已结束的来源，同时移除未来来源对 BM25 文档频率和平均长度的影响。使用隔离数据库副本，不修改运行中的记忆。

## 四组机制

| 组 | 检索机制 |
| --- | --- |
| A | 当前 Timeline 默认词法排序和阈值；检查与此前冻结候选及选择完全一致 |
| B | BM25 词特征与字符特征的排名融合 |
| C | B 的词法排名与 Qwen 向量排名做纯 RRF，不叠加原始相似度 |
| D | 原文全文、句子及相邻句子片段的词法排名，按最佳片段聚合回来源 |

C 只读取已有 `text-embedding-v3`、1024 维缓存；缺少向量时明确失败，不退化为 B。D 保留原文偏移并逐条验证可追溯性。该对照检验共享候选池内的排序变化，不检验扩大全库候选召回。

## 指标口径

| 指标 | 计算方式与边界 |
| --- | --- |
| 选择题准确率 | 所选字母直接匹配标准选项，不使用 LLM Judge；每组分母为 90 次回答 |
| 回答覆盖率 | 有效 A/B/C/D 输出比例，不使用 LLM Judge；本协议强制选择，100% 不代表证据充足 |
| 回答证据支持度 | qwen-flash 判断所选选项是否被检索原文支持，不接收标准答案；空证据判为不支持 |
| 同时选对且有支持 | 标准选项正确并且支持度判断为真的次数 / 90，属于两项结果的联合诊断 |
| 标准 Recall/MRR/nDCG | 需要完整来源相关性标注，当前未具备，保持 `null` |
| 目标时刻代理指标 | 用事后目标时间标注计算来源重叠；不能替代标准来源相关性或答题正确率 |

选项本身是合法输入，不等于正确答案泄漏；本轮只用题干检索是冻结的实验设置，不是 EgoLifeQA 禁止用选项检索。尚未开展题干加选项检索的消融。

三个 seed 的检索选择一致，模型回答并非完全相同。按 seed 17/43/91，A 分别答对 8/8/9 题，B 为 6/6/7，C 为 9/10/10，D 为 6/5/7，每个 seed 都是同一批 30 题。

C 相对 A 的题目微平均准确率高 4.44 个百分点，但按 22 个目标日/小时视频组等权比较，仅高 2.27 个百分点，组级 bootstrap 95% 区间为 [-17.42，21.97] 个百分点。B、D 相对 A 的组平均差分别为 -9.09、-10.61 个百分点，区间也都包含 0。样本只有 30 题和一位参与者，不据此宣称稳定优劣。

准确率由标准选项直接匹配；支持度由独立调用的 qwen-flash 评审，二者不是同一指标。C 的 29 次正确回答中，23 次未被评审判为有证据支持。该现象提示强制选择下存在正确但缺乏可验证支持的答案，不能把准确率上升直接等同于记忆检索改善；评审本身也可能出错。所有组的支持度仍低，不足以保留为生产优化。

计数与分母分别列示，三个 seed 的 90 次回答不代表 90 个独立题目。费用未测量，tokens 来自供应商响应，不据此自行估算账单。

标准 Recall/MRR/nDCG 需要来源相关性标注；当前官方目标时刻只支持时间重叠代理指标，因此两者分开列示。代理 MRR 使用完整候选排序；nDCG@5 按所有可见目标片段归一化。目标片段 Recall 只在有可见目标片段的题目上平均，Hit/MRR/nDCG 包含全部题目。它们都不证明完整答案证据被召回。

## 调用与验证

最终 r2 目录累计 466 次请求：3 次预检（充值前 1 次失败、充值后 2 次成功）、361 次回答尝试和 102 次评审。回答中的 1 次网络连接失败已补跑成功，最终每组都是 90 次有效回答，格式失败为 0，评审失败为 0。初版目录还保留充值前另一次失败预检，不包含在 r2 的 466 次中。

本轮没有新 embedding 调用，C 使用已有向量缓存。回答不使用缓存；证据评审复用相同问题、答案和证据的结果，空证据直接判为不支持。补跑后最终汇总阶段的评审缓存命中为 A/B/C/D：75/81/81/81 次；调用次数统计的是 r2 累计请求，两者的统计窗口不同，不应相加当作独立评审数。评审调用由首次遇到该组合的组承担，不代表该算法固有成本。

检索计时沿用本轮冻结的 360 条检索记录；回答计时来自充值后的调用。表中“检索加回答”是两阶段耗时相加，不是完整实时语音对话延迟，也不含失败后等待重试时间、入库、索引构建或 Judge。实际账单费用未测量，仍为 `null`。

44 项相关测试通过，包括选择题输入边界、时间与来源边界、未来文档频率隔离、纯排名融合、片段回溯和不可用指标语义；汇总字段澄清后，7 项新增测试复验通过。

[结果验证](../artifacts/egolife-abcd-mcq-20260914-r2/verification.json)已通过，核对 360 条组合完整性、共享候选、A 基线复现、三个 seed 的检索一致性、来源时间、原文偏移及标准答案评分，并检查 463 条回答/评审请求的输入字段。冻结实验代码哈希保持一致；本次只执行补跑和更新结果文档，没有修改答题或检索实现。Judge 没有人工复核，仍存在模型家族相关偏差。
