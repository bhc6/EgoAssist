# 实时异常处理与验证

2026-09-14 初次排查确认百炼返回 HTTP 400、错误码 `Arrearage`，属于账户计费限制。Omni WebSocket 同时返回 `Access denied`。当时的代码修复已在本地 8770 实例生效，账户恢复尚未验证；下文初次验证结果保留该时间点的状态。

后续恢复：用户充值后，`qwen-flash` 预检成功，[A-D 四选一评测](EGOLIFE_ABCD_MCQ_2026-09-14.md)已完成 360 次有效回答和 102 次评审调用，确认文本模型服务恢复。Omni 实时语音连接和历史记忆作业的恢复未在这轮离线评测中复测，不能由文本 API 成功推断它们已恢复。

## 异常证据

- 当晚使用记录中出现 681 条 `turn router HTTP 400` 记忆错误事件，这是错误事件数，不是独立任务数。
- 464 条音频转写不能全部视为用户提问，其中可能包含环境语音。
- 状态轮询重复返回路由提示词、来源场景及历史场景记录，使单次 `/api/state` 响应达到约 5.3 MB。
- `Arrearage` 不说明具体欠费金额，也不能据此认定是哪次实验产生费用。计费详情需要在对应阿里云账户核查，参见[供应商错误说明](https://help.aliyun.com/zh/model-studio/error-code#overdue-payment)。

## 已实施的修复

- 语义路由区分可重试和不可重试错误；账户拒绝后停止该路由实例的后续网络请求，并向页面报告服务不可用。限流及暂时性服务错误仍可重试。
- 记忆恢复遇到不可重试错误时立即保留失败状态和原输入，避免重复解析；手动重试会重置该工作器的账户阻断状态。
- 捕获 Omni SDK 仅写日志的连接错误，账户拒绝后停止自动重连，清理待发送音频和视觉请求状态。
- 状态轮询去除重复提示词和来源场景，场景显示限定为最近 100 条。原始日志、完整场景存储、问题、答案及记忆状态保留；完整提示词仍可通过所属用户的审计接口查看。

## 恢复步骤

1. 在当前 API Key 所属阿里云账户处理百炼计费限制；如果仍有访问拒绝，再检查密钥和模型权限。
2. 在浏览器结束并重新建立实时连接；必要时重启服务，以重新创建连接和路由实例。
3. 用一次简短交互确认回答恢复，再在提示词审计中核对失败原话，对需要保留的记录点击“重试解析”。本轮没有批量重放历史转写。

本次处理解决的是供应商失败后的应用行为和页面数据负载，不构成检索准确率或模型能力改善的实验结论。
