# 记忆与声画指代边界

## 结论

- 只有明确的“请记住/保存”等记忆意图，或已经确认的记忆候选，才写入 TimelineMemory。
- 被动观测不会把“吃药、吞咽、拿起饮料”等视觉猜测直接写成事实。观测模型被要求只返回当前帧可见证据；药物种类、剂量、是否吞下和意图都必须保持未知。产品若要记录，需要用户口头确认或显式保存。
- 当画面对用户有足够价值但仍不确定时，隔离的主动门会提出一个最小澄清问题。确认会回到正常记忆意图并写入，拒绝、沉默或回答不匹配则保持未知；澄清本身不会写入事实。
- 语音、画面和问题按 `turnId`、接收时间及帧时间对齐。画面只能回答实际返回的可见证据，例如“右手附近有饮料”；无法区分左右手、人物或遮挡时，应返回不确定，不把时间 coincidence 当身份关联。
- 每张卡片同时保存 `happenedAt`、`recordedAt`、时区和原始来源。相对时间按服务端 `Asia/Shanghai` 时钟解析。检索遇到模型把“昨天讨论的前天约定”错误嵌套时，会保留原解释并额外评估独立民用日解释，避免漏检；审计中仍可看到原始解析。

## 真实验收

`scripts/verify_real_social_memory.py` 使用真实 Qwen 写入两条不同日期、人物和场景的约定，再跨案例追问。2026-09-09 真实结果：通过，返回 2026-09-07 的青色样机约定，排除了红色文件；检索 4.4 ms，语义路由 1.59 s，首音频 0.90 s。

`scripts/verify_memory_workspace_browser.py` 使用真实 Qwen 验证文本记忆写入、跨轮检索、页面刷新恢复、检索证据展开、报告异步生成、中文输入法回车与 Shift+Enter。2026-09-09：通过；无模型 mock，桌面和 390px 页面均无横向溢出。

## 仍然不能宣称的能力

没有真实眼镜、麦克风阵列、深度相机和连续跟踪数据时，不能宣称已经可靠识别多人身份、唇动归因、右手持物或药物摄入。当前系统保留原始音视频证据和模型边界，未知情况会显示为未知，并允许用户随后明确保存。
