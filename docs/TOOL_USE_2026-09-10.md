# 工具链路：实现与真实验收

## 决策依据

参考 DeepSeek Harness 的 [architecture](https://github.com/deepseek-ai/deepseek-harness/blob/c389f96bf3a9b6807cb71ed6bdad5849be0df6d8/docs/architecture.md) 和 [tool execution pipeline](https://github.com/deepseek-ai/deepseek-harness/blob/c389f96bf3a9b6807cb71ed6bdad5849be0df6d8/docs/tool-execution-pipeline.md)：执行前保存调用、统一参数校验、调用与结果成对保留、界面从日志恢复。参考 Claude Code 官方 [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) 的中断恢复、并行工具结果保留及未知发送结果不盲目重试修复；未读取其私有实现。Claude 文档站本次返回 HTTP 403。

真实 Qwen Realtime 测试没有获得可靠的 function call。尝试 Flash、Plus、实际 user item、两种声明格式和必填参数后，仍出现模型口述虚构文件大小或拒绝调用。不能用模型说“已经执行”证明执行成功。

当前链路是 Qwen 文本 API 原生 `tool_calls` -> 本地共享执行器 -> 持久 `tool_result` -> Qwen Realtime 文字与音频。没有关键词解析工具名称。无工具、主动播报、工具结果续答及同一原问题已有执行收据时跳过额外工具判断。已执行的资料请求不会再次请求工具模型。

## 代码与边界

- `realtime/tool_model.py`：异步 HTTP、连接复用、默认 `qwen3-max`、8 秒决策超时、完整提示词与 usage 审计。环境变量为 `EGOASSIST_TOOL_MODEL` / `EGOASSIST_TOOL_TIMEOUT`。
- `realtime/tool_loop.py`：每次至多四个调用，依序执行并只生成一次批次答复；不推测调用间的数据依赖，不进行无限自主循环。
- `realtime/tools.py`：统一 JSON Schema 校验与执行器；内置资料、提醒也经过校验。内部 Demo 默认自动通过工具确认，文字和语音均可调用。可用性与参数校验保留。
- `realtime/context_harness.py`：追加调用、执行认领、结果、原问题；工具界面使用增量投影，避免每次刷新复制全量会话。
- `console/tool_activity.js`：真实状态、原问题、模型判断耗时、提示词、参数、结果、Token 和资料查看入口。资料 `resolved` 表示可供查看，不代表查看器已打开。
- `prompts/tool_use.json`：独立可调提示词；缺参数时保留模型的澄清信息，不捏造参数。

取消未完成的工具判断会释放回答队列；已经开始的调用需要提交真实结果，即使连接关闭也保留原问题归属。程序硬退出造成“执行开始但没有结果”时，恢复为 `interrupted` / 未确认效果，禁止自动重复。此机制不是对任意外部服务的 exactly-once 保证。接入慢外部工具时必须提供自己的有限执行期限与幂等键，目前内置执行器为本地解析或任务入队。

全量确定性回归：441 项，0 失败，0 跳过，`outputs/tool-review-tests-final.xml`。包含批次去重、严格参数校验、超时、取消、执行中关闭、结果归属与前端状态恢复。已有 aiohttp 弃用提示及沙箱 pytest 缓存权限警告不影响测试执行。

最后的资料按钮与措辞修改后，另跑 38 项针对性测试及上述 `tools-viewer-final` 真实验收；浏览器脚本语法检查通过。

复现：

```powershell
.venv\Scripts\python.exe -m pytest -q --junitxml=outputs/tool-review-tests-final.xml
.venv\Scripts\python.exe scripts/run_experiment.py --script verify_tool_use_real.py --name tools-real --timeout 180
.venv\Scripts\python.exe scripts/run_experiment.py --script verify_shared_scene_browser.py --name tools-scene --timeout 240
```

验收脚本会连接真实 DashScope 并产生 API 费用。现有真实声画测试覆盖音频输入，但不等于每个工具都做过口述、ASR 和物理眼镜链路验收。外部人工求助等未配置的能力仍不能声称执行成功。
