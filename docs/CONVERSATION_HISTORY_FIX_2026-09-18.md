# 对话记录不全：诊断与修复

日期：2026-09-18。

## 已确认原因

原页面使用 `workLedger.turnInbox` 展示“全部对话记录”，但实时状态只投影最近 100 条输入。没有历史分页入口，因此较早的问题消失于页面，并非已被删除。

回答展示又依赖 `answer.job` 完成状态和已完成的 assistant message。已持久化的 interrupted 消息被排除；没有普通回答任务的独立助手消息（例如记忆保存确认）也无法显示。被打断的原始语音与之后的后台补全无法同时回看。

本次冻结用户会话副本审计得到 163 条展示消息：123 条用户输入、40 条助手消息，其中 1 条是已保存的中断片段。这个数字是取样时刻的结果，不是正在持续输入的会话最终总数。

## 修复

- 新增只读 `/api/conversation`，校验登录和会话归属，使用稳定消息 ID 分页；每页最多 200 条，回复禁止公共缓存。
- 从持久化 `turn_inbox`、用户/助手 `message` 和已完成的后台文字回答构建独立展示投影。用户双重记录按 turnId 去重；助手按 responseId 去重。后台补全文字独立显示，保留此前的中断片段。
- 不把所有记录塞进实时状态。页面首次加载 50 条，提供“加载更早记录”，显示“已加载 X / Y 条已保存消息”。刷新时重新读取已加载范围，避免保留被删除的记录。
- 保留完整正文、换行和时间；中断内容标注“已生成片段，不代表全部播出”；后台补全单独标记。实时字幕按 responseId 累积，持久化后去重，未保存内容不标记为已保存。
- 会话切换、退出时清空临时记录，迟到的请求不能覆盖新会话。实时状态中的最近问题进度和取消、重试操作保留在“最近问题的处理状态”展开项。
- 历史显示直接读取已有证据，不修改原始对话，不重新调用模型生成旧答案。

## 验证

相关测试 28 项通过，覆盖超过 100 条记录、跨页去重、重启、中断/独立/后台消息、长文本、只读、删除后投影失效以及跨账户隔离。

最终全量回归：748 项通过，0 失败/错误/跳过。保留既有 aiohttp 弃用与 pytest 缓存目录权限警告。

真实 Edge 浏览器验证（本地隔离账号与夹具数据）：

1. 加载全部 128 条消息，包含中断回答、记忆确认和超过 2000 字的完整回答。
2. 一次新增 55 条后，183 条记录无缺口；刷新再加载仍完整。
3. 实时片段中断后保留，落盘后只有一条。
4. 切换两个会话不会串入对方内容。
5. 1440 和 390 像素宽页面无横向溢出、无 JavaScript 错误；不执行对话正文中的 HTML。

证据：

- `outputs/conversation-history-20260918/focused-r2.xml`
- `outputs/conversation-history-20260918/regression.xml`
- `outputs/conversation-history-browser-20260918-r2/report.json`
- 同目录 `history-1440.png`、`history-390.png` 与真实日志冻结副本。

首轮单元测试曾因断言未考虑既有入库逻辑去除正文末尾空格而失败，修正测试后通过；没有改变原始入库格式。

本次解决已保存记录的完整展示。如果录音从未转写成功，或回答在崩溃前没有任何持久化正文，页面不能凭空补回其内容。当前没有证据说明所有缺失内容都是此类源头丢失。
