# EgoLife 留出题目测试结果：2026-09-14

后续回归：[A-D 四选一统一对照](EGOLIFE_ABCD_MCQ_2026-09-14.md)复用了本文已经暴露的 30 题，固定 `qwen-flash` 并强制四选一，已完成 360 次有效回答。本文的 Omni/模块化结果采用允许拒答政策，保留原始结果，不能与后续准确率直接相减来宣称模型或检索改善。

## 结论

**本轮独立题目测试已完成，两种模式的绝对效果均不达标，不提升模块化为默认方案。** Omni 的官方选择题准确率为 10.0%，模块化为 5.6%；共享检索表现不足，单纯替换回答模型没有解决证据缺失问题。此前简单合成场景的 100% 通过率不能外推到 EgoLife。

此处“独立”指相对于本项目已记录开发/调参过程的留出题目，不证明未进入供应商预训练数据。抽取官方 500 题中的 30 题，不是完整官方排行榜结果。仍为一名参与者的不同日期，输入为官方描述和转写，不是原始视频/音频，因此不能评价 Omni 与分离式 ASR/VL 的感知能力孰优。

## 两种模式

| 指标 | Omni | 模块化 |
| --- | ---: | ---: |
| 模型请求完成 | 90/90 | 90/90 |
| 官方选项正确率 | **9/90，10.0%** | **5/90，5.6%** |
| seed 17 正确数 | 3/30 | 2/30 |
| seed 43 正确数 | 3/30 | 2/30 |
| seed 91 正确数 | 3/30 | 1/30 |
| 回答覆盖率 | 21/90，23.3% | 15/90，16.7% |
| 明确拒答 | 68/90 | 75/90 |
| 格式不合规 | 1/90 | 0/90 |
| 已回答部分的官方准确率 | 9/21，42.9% | 5/15，33.3% |
| 已回答部分的证据支持度 | 9/21，42.9% | 7/15，46.7% |
| 首段文本中位数 | 206 ms | 306 ms |
| 首段音频中位数 | 401 ms | 549 ms |
| 生成结束中位数 | 475 ms | 755 ms |

准确率直接匹配官方正确选项，**不是 LLM Judge**。拒答在官方选择题准确率中记为未答对；分数低于四选一随机猜测的 25% 不等于模型只会猜错，而是这里按证据不足时拒答的固定政策运行，覆盖率很低。

证据支持度是额外的 qwen-flash 评审，判断所选答案是否被检索材料支持，不看 gold。它与官方准确率是不同指标。例如文字材料可能支持一个局部结论，但不能证明其符合问题所指的具体时刻。评审只看所选选项文本及全部检索证据，不是验证模型自带引用，也没有真人标注。模型家族相关偏差仍存在。

Omni 的一次格式失败为包含 ABSTAIN 的解释性句子，未按协议只返回单个标记；按运行前规则保留格式失败，没有事后宽松解析。全部 180 次请求成功结束，没有将 API 失败伪装成错误答案。

这轮多数输出只有单个选项或拒答标记，首音延迟不能视作复杂回答或真实语音对话的端到端延迟。测试没有调用原始语音识别或图像观察；模块化此处实际执行文本模型和 TTS。

| 检索中位耗时 | 97 ms |
| 本轮增量入库累计耗时 | 654 秒 |

目标覆盖只用 gold 时刻做事后区间相交诊断；不是标准来源相关性 Recall 或完整证据召回，不能把 0/30 直接称为所有相关证据都没召回。部分相邻材料仍可能包含答案，所以目标点未覆盖时依然可能答对。

当前证据表明候选截断、硬准入和排序共同存在损失；本轮没有做放宽约束的消融，不能将全部损失归因于某一项。不会因为看到测试结果就补回 gold 来源或调大候选池。修复这些问题应回到开发集，后续验证另取未使用题目。

## 调用与验证

模块化回答共 180 次模型请求，即文本 90 次、TTS 90 次；应用推理缓存命中为 0。Omni 的持续实时会话未建立可比调用计数，保持 null。两种模式都保留了供应商原始用量事件，但没有统一结算实际账单，费用为 null。

证据评审共 11 次实际请求，25 次复用相同问题/答案/证据的缓存判断；不将缓存时延算成新模型调用。评审的所有输入输出有审计记录，未使用 gold 作为判断输入。

结果完整性校验通过：180 个预期配对结果齐全且无重复，冻结文件哈希不变，所有 selected 属于 hard candidates，候选片段在提问前已结束，证据文本与原文逐字一致，评分没有改写预测。

SQL 查重优化通过时间、身份、指代、更正、来源与检索专项回归；旧运行上的 21 组 SQL 查询结果集合一致，前五题优化前后的硬候选和最终选择也完全一致。没有更改默认检索或模型选择。
