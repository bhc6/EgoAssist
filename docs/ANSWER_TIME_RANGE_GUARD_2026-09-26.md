# 时间统计回答边界（2026-09-26）

## 问题

用户问“我今天喝了几次水”时，JEV 曾把问题判成普通记忆/回答。记忆读取随后超时，回答器退回当前摄像头窗口，于是把一段约十几秒的局部画面说成全天统计，并把水瓶离开画面解释成动作完成。

这不是视觉模型能证明的结论。当前窗口最多支持“画面中观察到一次疑似饮水”，不能证明全天次数，也不能把未继续看到动作当成没有其他事件。

## 修复

- Decisions 路由增加必填的 `evidenceScope` 有限判断：`live-window`、`stored-memory`、`temporal-history`、`none`。
- `temporal-history` 和 `stored-memory` 只能进入历史检索；不能复用当前视觉直答。
- 证据范围只约束回答取证，不能覆盖 JEV 已确认的保存意图与授权；“记住我的柜号”不会被误当作查询。
- 复杂解析返回后再次校验证据范围，防止第二阶段把历史问题改回普通视觉回答或写入记忆。
- 回答提示规定：统计只能使用指定时间段内、带事件时间的已接受记录；记忆读取降级、超时或没有合格记录时必须说无法确定。
- 当前视觉提示明确：物体离开画面不代表动作完成，短窗口不代表完整一天。

关键词识别只保留为通用故障兜底，不承担领域词表或事实提取；主路由依据 JEV 输出的证据范围，时间范围解析继续由现有时间引擎完成。

## 正确回答边界

当今天的带时间饮水记录不完整或记忆读取失败时，应回答：

> 当前记录不足以确定今天总共喝了几次水。这个画面最多显示一次疑似饮水，不能代表全天总数。
